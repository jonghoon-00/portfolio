## 핵심 구현 및 판단

### 1. 지도 기반 게시글 표시 구조 설계

#### **문제 상황**

게시글 정보와 위치 데이터를 함께 표현해야 했습니다.

지도 마커와 게시글 상세 정보 간의 연결 구조를 명확히 설계할 필요가 있었습니다.

#### **판단**

지도 UI는 시각적 보조 수단으로 활용하고,  
데이터의 중심은 게시글에 두는 구조가 유지보수에 유리하다고 판단했습니다.

#### **해결**

- 게시글 데이터를 기준으로 지도 마커를 생성
- 마커 클릭 시 해당 게시글 상세 정보를 팝업으로 노출
- `react-kakao-maps-sdk`를 활용해 지도 초기화 및 마커 관리

#### **결과**

- 게시글과 지도 간 역할이 분리된 명확한 구조 확보
- 지도 UI 확장(클러스터링 등)을 고려할 수 있는 기반 마련

### 2. 댓글 CRUD 및 사용자 경험 개선

#### **문제 상황**

댓글 작성·수정·삭제 시 화면 지연이 발생하여  
사용자에게 즉각적인 피드백을 주기 어려웠습니다.

#### **판단**

커뮤니티 서비스 특성상 댓글 반응 속도가 UX에 직접적인 영향을 준다고 판단했습니다.

#### **해결**

- React Query의 `useMutation`과 `optimistic update` 적용
- 로딩/에러 상태를 UI에 명확히 반영

#### **결과**

- 사용자 인터랙션에 즉각 반응하는 댓글 UX 구현
- 서버 응답 지연 상황에서도 안정적인 화면 유지
