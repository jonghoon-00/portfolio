**핵심 구현**

- 권한별 라우팅 제어 (ProtectedRoute)
- Zustand + Axios 인터셉터를 활용한 토큰 관리 자동화
- TanStack Query를 통한 서버 상태 관리
- Tailwind 플러그인 커스터마이징으로 재사용 가능한 스타일 클래스 구성
